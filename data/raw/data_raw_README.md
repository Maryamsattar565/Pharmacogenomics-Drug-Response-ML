# Raw Data

This folder contains the original datasets used in the project.

## Source Files

- `model_list_20260616.csv` — Cell Model Passports model information.
- `rnaseq_merged_rsem_tpm_20260323.csv` — Cell Model Passports RNA-seq RSEM TPM expression data.
- `GDSC2_fitted_dose_response_27Oct23.xlsx` — GDSC2 drug-response data obtained from Cell Model Passports.

The original files are not included in this repository because of their large size.

Processed datasets are stored separately in:

```
data/processed/
```
