# Processed Data

This folder contains intermediate and final processed datasets generated by the pipeline described in `notebooks/Pharmacogenomic_ML.ipynb`.

## Included Files

- `only_lung_model.csv` — Lung-specific cancer model list, filtered from the Cell Model Passports model list (`tissue = lung`).
- `LUNG_GDSC2.csv` — GDSC2 drug-response data filtered to lung cancer models.

## Files Not Included

The following processed files are **not included** in this repository because of their large file size, which exceeds GitHub's per-file limits:

- `RNA_FULL_processeeD.csv` (~47 MB) — Processed lung RNA-seq expression matrix (247 lung models × filtered genes).
- `Pharmacogenomics_Finale.csv` (~170 MB) — Final merged pharmacogenomics dataset (RNA-seq expression + GDSC2 drug response) used as direct input to the machine-learning stage.

Both files can be regenerated locally by running `notebooks/Pharmacogenomic_ML.ipynb` from the beginning, using the raw source files listed in `data/raw/README.md`.
